# צבעונית – מסע הצבעים

משחק זיכרון וקצב לגילאי 8+. צבעונית מנגנת רצף של צבעים וצלילים, והשחקן חוזר עליו. כל הצלחה מחזירה צבע לעולם האפור.

- **5 עולמות × 6 שלבים**, כל עולם עם מכניקה משלו: לפי הסדר, בקצב, הפוך, בחושך (לפי שמיעה בלבד), והפתעה.
- **אתגר אינסופי** עם שיא אישי.
- **ארון בגדים**: כובעים שנפתחים לפי כוכבים.
- **הגדרות**: צלילים, רטט, מצב עזרה (קצב איטי יותר), צורות על הכפתורים (לעיוורון צבעים), עברית/English.
- בלי פרסומות, בלי רכישות, בלי איסוף מידע. ההתקדמות נשמרת במכשיר בלבד.

## הרצה במחשב

```bash
node serve.js
```

ואז לפתוח http://localhost:5173

## הפיכה לאפליקציית אנדרואיד (Google Play)

המשחק עטוף ב-[Capacitor](https://capacitorjs.com), שהופך אתר לאפליקציית אנדרואיד אמיתית.

### פעם אחת: התקנות
1. להתקין את [Android Studio](https://developer.android.com/studio) (כולל Android SDK).
2. בתיקיית הפרויקט:
   ```bash
   npm install
   npx cap add android
   ```

### בכל עדכון של המשחק
```bash
npx cap sync android
npx cap open android
```

### בניית קובץ להעלאה
ב-Android Studio: **Build → Generate Signed App Bundle / APK → Android App Bundle**.
- בפעם הראשונה ליצור **keystore** (מפתח חתימה). **לשמור אותו ואת הסיסמה במקום בטוח** – בלעדיו אי אפשר לעדכן את האפליקציה אחר כך.
- התוצאה: קובץ `.aab` שמעלים ל-Play Console.

### לפני ההעלאה ל-Play Console
- **מספר גרסה**: ב-`android/app/build.gradle` להעלות את `versionCode` בכל העלאה.
- **targetSdk**: לוודא שהוא עומד בדרישה העדכנית של Google Play (מופיעה ב-Play Console).
- **אייקון**: להמיר את `www/icon.svg` ל-PNG בגודל 512×512 לחנות, ולאייקון האפליקציה להשתמש ב-Android Studio → **New → Image Asset**.
- **מדיניות פרטיות**: Google דורשת קישור. אפשר להעלות את `www/privacy.html` ל-GitHub Pages ולתת את הקישור. לבדוק את כתובת המייל שמופיעה בו.
- **קהל יעד**: אם בוחרים גילאים מתחת ל-13, האפליקציה נכנסת לתוכנית **Families** של Google. המשחק כבר עומד בעיקר הדרישות (אין פרסומות, אין איסוף מידע), אבל צריך למלא את השאלון בקונסול.
- **צילומי מסך**: לפחות 2 צילומי מסך של טלפון.
- **חשבון מפתח פרטי חדש**: Google דורשת בדיקה סגורה עם 12 בודקים לפחות למשך 14 יום לפני פרסום ציבורי.

## מבנה הקבצים
- `www/` – המשחק עצמו (`index.html`, `style.css`, `game.js`)
- `capacitor.config.json` – הגדרות האפליקציה (`appId: com.scitedragames.tzavvanit`)
- `serve.js` – שרת קטן לבדיקה במחשב
