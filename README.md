# צבעונית / Tzavvanit

משחק זיכרון וקצב לגילאי 8+, של Scitedra Games.

## מה יש בריפו

| תיקייה | מה זה |
|---|---|
| [`tzavvanit/`](tzavvanit/) | **הגרסה הראשית**: המשחק ב-HTML5, כולל הגדרות Capacitor לבניית אפליקציית אנדרואיד. ההוראות ב-[`tzavvanit/README.md`](tzavvanit/README.md) |
| `Build/`, `TemplateData/`, `index.html` | אב־הטיפוס הישן ב-Unity WebGL (build בלבד, בלי קוד מקור) |

## הרצה מהירה

```bash
node tzavvanit/serve.js
```

ואז לפתוח http://localhost:5173
